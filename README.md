# Jala Technologies Java Assignment

This repository contains my completed Java programming assignment for Jala Technologies.

The assignment covers fundamental and advanced Java concepts.

It includes programs based on Java Basics and Operators.

Looping concepts are implemented using different loop structures.

Array programs cover common array operations and problems.

Static members and String operations are also included.

Inheritance concepts are demonstrated with practical examples.

Access modifiers and Abstract Classes are covered.

Interface concepts and multiple interface implementations are included.

The assignment also covers `this`, `super`, and Constructors.

Method Overloading and Exception Handling programs are included.

Java I/O programs demonstrate file reading and writing operations.

Collections programs cover ArrayList, HashMap, and HashSet.
